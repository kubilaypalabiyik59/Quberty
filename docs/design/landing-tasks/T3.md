# Task T3 — Hero, Problem and OneSystem sections

Create exactly these three files, and nothing else:

- `frontend/src/app/(landing)/_components/Hero.tsx`
- `frontend/src/app/(landing)/_components/Problem.tsx`
- `frontend/src/app/(landing)/_components/OneSystem.tsx`

All three are **server components**: no `'use client'`. Each exports one named component with
props `{ t: LandingDictionary }`.

## What already exists (do not modify)

- `@/app/(landing)/i18n/types`: `LandingDictionary`. The relevant parts:
  - `t.hero`: `{ eyebrow, title, subtitle, primary, secondary: string; proof: string[] }`
  - `t.problem`: `{ title, intro: string; items: { title, body: string }[] }` (3 items)
  - `t.oneSystem`: `{ title, intro, ledgerLine: string; tiles: { title, body: string }[] }` (4 tiles)
- `@/app/(landing)/content`: `DEMO_EMAIL`, `SECTION_IDS` (`product`, `capabilities`, `how`).
- `@/app/(landing)/_components/CtaLink`: `CtaLink({ href, variant: 'primary' | 'outline' | 'ghost',
  size?: 'md' | 'lg', className?, children })`. This is a client component, and you may render it
  from a server component.
- `@/app/(landing)/_components/Reveal`: `Reveal({ children, className? })`. This is a client
  component and provides the fade-in on scroll.
- Icons come from `lucide-react`. Always pass `aria-hidden` and size them with `className`
  (`h-4 w-4` or `h-5 w-5`).
- Type scale tokens: `text-hero` (hero heading only), `text-section` (section titles), and
  `text-title`, `text-lead`, `text-body`, `text-caption`.

## Shared section pattern (Problem and OneSystem)

Both sections use this exact outer structure:

```tsx
<section id={...optional...} className="bg-bg py-24 sm:py-32">
  <div className="mx-auto max-w-6xl px-4 sm:px-6">
    <Reveal>
      <h2 className="text-section font-semibold text-fg">{...title}</h2>
      <p className="mt-4 max-w-2xl text-lead text-fg-muted">{...intro}</p>
      {/* section body */}
    </Reveal>
  </div>
</section>
```

Cards in both sections use this pattern:

```tsx
<div className="rounded-surface border border-border bg-surface p-6">
  <Icon aria-hidden className="h-5 w-5 text-accent" />
  <h3 className="mt-4 text-title font-semibold text-fg">{...}</h3>
  <p className="mt-2 text-body text-fg-muted">{...}</p>
</div>
```

Card keys: use the item's `title` as the React `key`.

## Hero

- It is a `<section>` with classes `relative flex min-h-[calc(100svh-4rem)] items-center`. It has
  **no background**, because the animated brand stage shows through behind it. This is the only
  arbitrary Tailwind value allowed.
- Inside the section: `<div className="mx-auto w-full max-w-6xl px-4 py-16 sm:px-6">`, which holds
  `<div className="max-w-3xl lg:w-3/5">` with the content below, in this order:
  1. `<p className="text-caption font-medium uppercase tracking-widest text-accent">{t.hero.eyebrow}</p>`
  2. `<h1 className="mt-4 text-hero font-semibold text-fg">{t.hero.title}</h1>`. This is the page's
     only `<h1>`.
  3. `<p className="mt-6 max-w-xl text-lead text-fg-muted">{t.hero.subtitle}</p>`
  4. A `<div className="mt-8 flex flex-wrap gap-3">` with two CTAs:
     `<CtaLink href={\`mailto:${DEMO_EMAIL}\`} variant="primary" size="lg">{t.hero.primary}</CtaLink>`
     and
     `<CtaLink href={\`#${SECTION_IDS.how}\`} variant="outline" size="lg">{t.hero.secondary}</CtaLink>`.
  5. `<ul className="mt-8 flex flex-col gap-2 sm:flex-row sm:flex-wrap sm:gap-x-6">`, with one
     `<li className="flex items-center gap-2 text-caption text-fg-muted">` per `t.hero.proof`
     entry. Each `<li>` holds a `Check` icon (`h-4 w-4 text-accent`, `aria-hidden`) and then the
     text. Use the text as the `key`.
- The Hero does **not** use `Reveal`, because it is visible on load.

## Problem

- It follows the shared section pattern and has no `id`.
- Body: `<div className="mt-12 grid gap-4 md:grid-cols-3">`, with one card per
  `t.problem.items` entry.
- Icons by index: 0 → `FileSpreadsheet`, 1 → `Boxes`, 2 → `Clock`. Put them in a
  `const ICONS = [FileSpreadsheet, Boxes, Clock] as const;` at module level and pick the icon with
  `ICONS[i]`.

## OneSystem

- It follows the shared section pattern with `id={SECTION_IDS.product}`.
- Body: `<div className="mt-12 grid gap-4 sm:grid-cols-2 lg:grid-cols-4">`, with one card per
  `t.oneSystem.tiles` entry.
- Icons by index: `LayoutDashboard`, `Store`, `ShoppingBag`, `Warehouse`, held in a module-level
  `ICONS` array as in Problem.
- After the grid: `<p className="mt-4 rounded-surface border border-border bg-surface px-6 py-4 text-center text-lead text-fg">{t.oneSystem.ledgerLine}</p>`.
