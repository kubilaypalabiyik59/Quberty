# Task T6 — integration fixes found in the browser

The assembled page was tested in Chromium at 360, 768 and 1440 px in all three languages. Two
defects came from the architect's spec, not from your code. Fix exactly these, in these two
files only:

- `frontend/src/app/(landing)/_components/Reveal.tsx`
- `frontend/src/app/(landing)/_components/LandingHeader.tsx`

Both files are in the chat.

## 1. Reveal: content invisible for reduced-motion users

The server renders the `motion.div` with `opacity:0`. In the browser, `useReducedMotion()` then
returns true and the component switches to the plain `<div>`, but React keeps the server's
`style="opacity:0"` during hydration. The content never appears.

Replace the whole component with this. It always renders the `motion.div` and lets CSS cancel
the hidden start state for reduced-motion users (`!` makes the rule beat the inline style):

```tsx
'use client';

import { motion } from 'framer-motion';
import type { ReactNode } from 'react';

import { cn } from '@/lib/utils';

/**
 * Fades its children up once as they scroll into view. Reduced-motion users get the final
 * state from CSS. The component must not branch on useReducedMotion(), because the server
 * render and the hydrated render would disagree.
 */
export function Reveal({ children, className }: { children: ReactNode; className?: string }) {
  return (
    <motion.div
      className={cn('motion-reduce:!transform-none motion-reduce:!opacity-100', className)}
      initial={{ opacity: 0, y: 12 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, margin: '-80px' }}
      transition={{ duration: 0.4, ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}
```

## 2. LandingHeader: Spanish header overflows at 768 px

At 768 px the three Spanish nav links, the switcher and both CTAs do not fit: the demo button is
cut off and the page scrolls sideways by 51 px. Two changes:

- On the `<nav>`, change `md:flex` to `lg:flex`. The class becomes
  `hidden items-center gap-6 lg:flex`.
- Add `whitespace-nowrap` to each of the three nav `<a>` classNames, so that "Cómo funciona"
  never breaks onto two lines.

Change nothing else.
