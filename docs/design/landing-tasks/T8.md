# Task T8 — animated mosaic field (Canvas2D)

Create exactly these two files, and nothing else:

- `frontend/src/app/(landing)/_components/mosaic.ts`: pure drawing logic, with no React
- `frontend/src/app/(landing)/_components/MosaicField.tsx`: the client component that owns the
  canvas

This is the landing page's background texture. It is a grid of 16 px cells whose brightness
moves in a slow wave, with a vignette at the edges and a soft bloom in the centre, coloured from
the cube's teal palette. It is a reduced take on the "Vignette Bloom" mosaic look.

## What already exists (do not modify)

- `frontend/src/app/(landing)/_components/landing.module.css` exports the class `mosaic`. It
  positions the canvas and controls its opacity. `MosaicField` does not import it: the parent
  passes it in as `className`.
- Nothing else is needed. There are no new dependencies.

## mosaic.ts

Colours are plain RGB number triples, and this is the one place in the project where they are
allowed, because canvas pixels need numbers. Export exactly these names.

```ts
/** Tuning for the landing mosaic field. */
export const MOSAIC = {
  cellSize: 16,      // CSS px per cell
  gap: 1,            // CSS px left dark between cells, so the grid reads
  contrast: 1.15,
  brightness: 0.12,
  vignette: 0.38,
  bloom: 0.25,
  waveAmplitude: 0.6,
  waveSpeed: 1,
} as const;

/** Colour stops from the page background to the cube's brightest teal. */
export const PALETTE = [
  [11, 18, 29],
  [12, 38, 48],
  [18, 88, 96],
  [64, 186, 180],
] as const;
```

Then write these three exported functions, each with a doc comment.

1. `smoothstep(edge0: number, edge1: number, x: number): number`. This is the standard
   smoothstep: clamp `(x - edge0) / (edge1 - edge0)` to [0, 1] and call it `k`, then return
   `k * k * (3 - 2 * k)`.

2. `cellLuminance(nx: number, ny: number, t: number): number`. Here `nx` and `ny` are the cell
   centre in the range 0..1, and `t` is time in seconds. Compute these steps, in order:
   - `w1 = Math.sin(nx * 6 + ny * 4 + t * 0.8)`
   - `w2 = Math.cos(ny * 5 - nx * 2 - t * 0.6)`
   - `wave = 0.5 + 0.5 * w1 * w2`
   - `l = 0.28 + MOSAIC.waveAmplitude * (wave - 0.5)`
   - `l = (l - 0.5) * MOSAIC.contrast + 0.5 + MOSAIC.brightness * 0.25`
   - `d = Math.hypot(nx - 0.5, ny - 0.5) / Math.SQRT1_2`. This is the distance from the centre,
     where 1 is a corner.
   - `l = l * (1 - MOSAIC.vignette * smoothstep(0.35, 1, d))`
   - `l = l + MOSAIC.bloom * Math.max(0, 1 - d / 0.45) ** 2`
   - return `l` clamped to [0, 1].

3. `paletteColor(l: number): readonly [number, number, number]`. This interpolates linearly
   through the 4 `PALETTE` stops, which are evenly spaced at l = 0, 1/3, 2/3 and 1:
   - `s = l * 3`
   - `i = Math.min(Math.floor(s), 2)`
   - `f = s - i`
   - each channel is `Math.round(a + (b - a) * f)`, where `a` comes from `PALETTE[i]` and `b` from
     `PALETTE[i + 1]`.

4. `drawMosaic(ctx: CanvasRenderingContext2D, width: number, height: number, t: number): void`.
   `width` and `height` are in CSS pixels; the context is already scaled for devicePixelRatio.
   - Fill the whole canvas with `PALETTE[0]`.
   - `cols = Math.ceil(width / MOSAIC.cellSize)` and `rows = Math.ceil(height / MOSAIC.cellSize)`.
   - For every cell (column `c`, row `r`):
     - `l = cellLuminance((c + 0.5) / cols, (r + 0.5) / rows, t)`
     - get its colour from `paletteColor(l)` and set `ctx.fillStyle` to `` `rgb(${r0} ${g0} ${b0})` ``;
     - `ctx.fillRect(c * size, r * size, size - MOSAIC.gap, size - MOSAIC.gap)`, where
       `size = MOSAIC.cellSize`.
   - Name the colour variables so that they do not shadow the row index `r`.

## MosaicField.tsx (client component)

- `'use client'` goes on the first line.
- `export function MosaicField({ className }: { className?: string })`, with a doc comment.
- It renders exactly `<canvas ref={canvasRef} aria-hidden className={className} />`.
- It uses one `useEffect` with an empty dependency array:
  - Get the 2D context and return early if it is missing.
  - `const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;`. Reading it
    inside the effect is fine, because it does not change what is rendered.
  - `resize()`:
    - `dpr = window.devicePixelRatio || 1`
    - set `canvas.width = canvas.clientWidth * dpr` and `canvas.height = canvas.clientHeight * dpr`
    - `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)`
    - then draw one frame with the current time.
  - Animation loop with `requestAnimationFrame`, **throttled to about 30 fps**:
    - skip the frame if less than 33 ms have passed since the last draw;
    - skip drawing while `document.hidden`;
    - otherwise call `drawMosaic(ctx, canvas.clientWidth, canvas.clientHeight, (now / 1000) * MOSAIC.waveSpeed)`.
  - If `reduce` is true, do not start the loop. Draw one frame at `t = 0` and redraw it on resize.
  - Listen to `resize` on `window`.
  - The cleanup cancels the animation frame and removes the listener.
