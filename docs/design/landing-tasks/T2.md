# Task T2 — landing header, language switcher, CTA link, reveal wrapper

Create exactly these four files, and nothing else:

- `frontend/src/app/(landing)/_components/Reveal.tsx`
- `frontend/src/app/(landing)/_components/CtaLink.tsx`
- `frontend/src/app/(landing)/_components/LanguageSwitcher.tsx`
- `frontend/src/app/(landing)/_components/LandingHeader.tsx`

## What already exists (do not modify)

- `@/app/(landing)/i18n/types`: `Locale`, `LOCALES` (`['en','tr','es'] as const`), and
  `LandingDictionary`. The dictionary has `t.nav = { product, capabilities, how, signIn, demo,
  languageLabel }`, all strings.
- `@/app/(landing)/content`: `DEMO_EMAIL`, `LANG_COOKIE` (`'quberty_lang'`), and
  `SECTION_IDS = { product: 'product', capabilities: 'capabilities', how: 'how-it-works' }`.
- `@/components/ui/Button` is a `'use client'` module that exports `buttonVariants`.
  `buttonVariants({ variant, size })` returns a class string, where
  `variant` is `'primary' | 'secondary' | 'outline' | 'ghost' | 'danger' | 'success'` and
  `size` is `'sm' | 'md' | 'lg' | 'icon'`.
- `@/components/brand/QubertyWordmark` exports
  `QubertyWordmark({ sweep?: 'loop' | 'once', className?: string })`. It is a server-safe
  component.
- `@/lib/utils` exports `cn(...classes)`.

## Reveal component (client)

- `'use client'`.
- Props: `{ children: React.ReactNode; className?: string }`.
- Uses `motion` and `useReducedMotion` from `framer-motion`.
  - If reduced motion is on, render a plain `<div className={className}>{children}</div>`.
  - Otherwise render a `motion.div` with `initial={{ opacity: 0, y: 12 }}`,
    `whileInView={{ opacity: 1, y: 0 }}`, `viewport={{ once: true, margin: '-80px' }}` and
    `transition={{ duration: 0.4, ease: 'easeOut' }}`.

## CtaLink component (client)

- `'use client'`. It must be a client component, because it calls `buttonVariants`.
- Props: `{ href: string; variant: 'primary' | 'outline' | 'ghost'; size?: 'md' | 'lg';
  className?: string; children: React.ReactNode }`. `size` defaults to `'md'`.
- Class: `cn(buttonVariants({ variant, size }), className)`.
- If `href` starts with `mailto:` or `http`, render `<a href={href} className=...>`. Otherwise
  render `next/link` `<Link href={href} className=...>`.

## LanguageSwitcher component (client)

- `'use client'`.
- Props: `{ locale: Locale; label: string }`.
- Renders a `<div role="group" aria-label={label}>` styled
  `inline-flex rounded-control border border-border p-0.5`.
- Inside it, one `<button type="button">` per entry of `LOCALES`:
  - Text is `l.toUpperCase()`. This is a language code, not copy, so it is allowed.
  - Attributes: `lang={l}` and `aria-pressed={l === locale}`.
  - Classes: `rounded-control px-2 py-1 text-caption font-medium transition-colors
    duration-quick`. Add `bg-surface-raised text-fg` when active and
    `text-fg-muted hover:text-fg` otherwise.
- On click, for a locale `l` that is not the current one:
  1. `document.cookie = \`${LANG_COOKIE}=${l}; path=/; max-age=31536000; samesite=lax\``
  2. `router.replace(\`/?lang=${l}\`, { scroll: false })`, with `useRouter` from
     `next/navigation`.

## LandingHeader component (server; no `'use client'`)

- Props: `{ t: LandingDictionary; locale: Locale }`.
- Structure:
  - `<header>` with classes `sticky top-0 z-40 border-b border-border bg-bg/70 backdrop-blur`.
  - Inside it, a `<div>` with classes `mx-auto flex h-16 max-w-6xl items-center justify-between
    gap-4 px-4 sm:px-6`.
- Left: a `next/link` to `/` with `aria-label="Quberty"`, wrapping
  `<QubertyWordmark sweep="once" className="text-lg" />`.
- Centre: a `<nav aria-label={t.nav.product}>` with classes `hidden items-center gap-6 md:flex`.
  It holds three `<a>` anchors, `href={\`#${SECTION_IDS.product}\`}`, then `capabilities`, then
  `how`. Their texts are `t.nav.product`, `t.nav.capabilities` and `t.nav.how`, and their classes
  are `text-body text-fg-muted transition-colors duration-quick hover:text-fg`.
- Right: a `<div>` with classes `flex items-center gap-2`, containing:
  - `<LanguageSwitcher locale={locale} label={t.nav.languageLabel} />`
  - `<CtaLink href="/login" variant="ghost" className="hidden sm:inline-flex">{t.nav.signIn}</CtaLink>`
  - `<CtaLink href={\`mailto:${DEMO_EMAIL}\`} variant="primary" className="hidden sm:inline-flex">{t.nav.demo}</CtaLink>`

  Below `sm` only the wordmark and the switcher show. The hero carries the CTAs on phones, and at
  360 px there is no room for a Spanish button label.
